
#### 刺客
- 加攻击，或降对方防御
- 加攻击次数

示例：
- 类型：通常属性
- 效果：攻击力+2 
- 估值：0.5
- 分析：这是一个最简单的加攻击刺客卡效。

示例：
- 类型：反应属性
- 效果: 攻击怪物时，此卡攻击力暂+3
- 估值: 0.5
- 分析：+2是基准，这里有概率调整。

示例：
- 类型：攻击技能
- 效果：被此卡攻击的怪物防御力-5至我方回合结束。
- 估值：1
- 分析：这是一个简单的减防御刺客卡效。

示例：
- 类型：技能
- 效果：我方一只怪物本回合攻击次数+1（或使用【攻击技能】次数+1）
- 估值：1
- 分析：类似于攻击次数+1


#### 坦克
- 加防御力，或降对方攻击
- 无效化攻击
- 嘲讽
- 死亡后反噬
- 不被战斗破坏

示例：
- 类型：通常属性
- 效果：防御力+5
- 估值：1
- 分析：这是一个最简单的加防御坦克卡效。

示例：
- 类型：通常属性
- 效果：对方所有怪物攻击力-3
- 估值：1
- 分析：范围保护

示例：
- 类型：反应属性
- 效果：当此卡被攻击时：进攻怪物本回合攻击力-5。
- 估值：1
- 分析：这是一个最简单的减攻击坦克卡效。

示例：
- 类型：反应属性
- 效果：当此卡被战斗破坏时：破坏该攻击怪物。
- 估值：0.5


#### 射手
- 直接伤害
  - 恐吓伤害（先减后加）
  - 延迟伤害（下次对方回合开始）
- 战斗增伤
- 信仰恢复
- 不被战斗伤害

示例：
- 类型：技能
- 效果：对方信仰-15。我方回合结束后，对方信仰+10。
- 估值：1
- 分析：这是一个恐吓伤害卡效。

示例：
- 类型：技能
- 效果：我方信仰+20。下次我方回合结束后，我方信仰-15。
- 估值：1
- 分析：保命两回合。


#### 法师
- 卡片破坏
  - 近似破坏，例如翻面等。
- 卡效保护
  - 预言防御
  - 怪物技能免疫
- 额外召唤，预言，技能。

示例：
- 类型：技能
- 效果：将对方场上一张正面牌翻面
- 估值：2
- 分析：将对方场上一张0级怪物翻面值1.4，将对方场上一张怪物卡翻面值1.9。将对方场上一张预言卡翻面值1.4。1.9量子叠加1.4，取2。




#### 辅助
- 查牌
- 获牌
  - 抽牌
  - 调牌（检索）
- 灵力调配
  - 获得灵力
  - 消耗对方灵力
  - 转移我方灵力
- 移动和交换位置

示例：
- 类型：技能
- 效果：查看对方一张手牌和一张盖牌
- 估值：1
- 分析：单看一张手牌或一张盖牌估值0.5.
