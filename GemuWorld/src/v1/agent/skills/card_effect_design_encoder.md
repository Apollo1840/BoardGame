# 效果估值

本文档提供一套将卡牌效果从自然语言描述转化为数值估值的系统方法。整个过程分为两步：

- **估值编码器**：将自然语言效果转写为标准事件表达式。
- **估值解码器**：将事件表达式映射为价值数值，用于检查单卡或组合的平衡性。

---

## 一、基本单位与事件构造器（编码器）

所有游戏行为均被描述为**事件** $E$，具有的状态描述为 **状态** $S$。

以下构造器用于生成标准效果表达式。

| 构造器 | 含义 | 方向说明 |
|:--|:--|:--|
| $\text{Cond}(E_1) + E_2$ | 当$E_1$发生时，$E_2$ |  |
| $\text{Cond}_\text{has}(S)*E_1$ | 若具有状态 $S$，$E_1$ |  |
| $Select(E1, E2, i) $ | 由i方选择事件1或事件2  |  |
| $Random(E1, E2) $ | 随机发生事件1或事件2  |  |

构造处的效果表达式可以包含随机变量，后面的例子会介绍。

### 1. 信仰 / 伤害
| 构造器 | 含义 | 方向说明 |
|:--|:--|:--|
| $\text{DMG}(x)$$ | 我方信仰变化 $x$ 点 | $x>0$ 恢复，$x<0$ 伤害 |
| $\text{DMG.E}(x)$$ | 我方信仰变化 $x$ 点 | 同$\text{DMG}(x)$ |
| $\text{DMG.A}(x)$$ | 我方信仰由于战斗变化 $x$ 点 | |
| $\text{DMG2}(x)$ | 伤害大于x时，伤害翻倍 | 同$\text{Cond}(\text{DMG}(-y))-\text{DMG}(-y), y \ge x$ |
| $\text{DMG0}(x)$ | 伤害大于x时，免疫伤害 | 同$\text{Cond}(\text{DMG}(-y))+\text{DMG}(y), y \ge x$ |


例如：

| 自然语言效果 | 事件表达式 | 说明 |
|:--|:--|:--|
| 我方信仰+5 | $\text{DMG}(5)$ | 直接使用 $\text{DMG}$，$x>0$ 表示恢复 |
| 对方信仰-3 | $-\text{DMG.E}(-3)$ | 对方受到伤害 → 对方信仰变化为负，取反 |
| 当我方造成伤害时：该次伤害翻倍 | $\text{DMG2}(1)$ |  |
| 当我方受到 5 点以上战斗伤害时，免疫该伤害 | $DMG0.A(5)$ | 免疫分解为条件成本 + 恢复等量信仰 |
| 对方信仰减半 | $-\text{DMG.E}(x/2)$, x=对方信仰期望 | 这里就使用了随机变量，估值时可以参考：DMG.E(25) |

### 2. 灵力
| 构造器 | 含义 |
|:--|:--|
| $\text{MANA}(i,j,x)$ | $i$ 方选择 $j$ 方某卡牌灵力变化 $x$ |
| $\text{MANA.rand}(x)$ | 随机获得 / 耗损灵力 |
| $\text{MANA.each}(x)$ | 全场灵力增益 |
| $\text{MANA.self}(x)$ | 自身灵力增益 |

拓展：
$\text{MANA} \in \text{TargetAct}$， TargetAct 均支持 (i, j, x) 定义 与.rand, .each, .self 后缀

例如：
| 自然语言效果 | 事件表达式 | 说明 |
|:--|:--|:--|
| 我方灵力+2 | $\text{MANA}(1,1,2)$ | 我方使我方灵力 +2 |
| 对方消耗我方 1 点灵力 | $\text{MANA}(-1,1,-1)$ | 对方发起（$i=-1$），我方灵力 -1 |
| 我方场上随机一只怪物灵力 +1 | $\text{MANA.rand}(1)$ | 随机增益 |
| 我方场上所有怪物灵力 +1 | $\text{MANA.each}(1)$ | 全体增益 |
| 此卡自身灵力 +1 | $\text{MANA.self}(1)$ | 仅对该卡生效 |
| 当对方使用 2 点以上灵力时，我方恢复 5 信仰 | $\text{Cond}(\text{MANA}(-1,-1,\le -2)) + \text{DMG}(5)$ | 对方消耗灵力视为条件 |
| 将双方所有灵力汇聚到我方一怪物上 | -$\text{MANA.rand(-x)} + \text{MANA.rand}(x) + \text{MANA.rand}(-y) + \text{MANA}(1, 1, y)$ x=对方灵力数目期望, y=双方灵力数目期望 | 对方消耗灵力视为条件 |

### 3. 攻击 / 防御
| 构造器 | 含义 |
|:--|:--|
|  $\text{V.ATK}$， $\text{V.DEF}$ | $\in \text{TargetAct}$，代表本回合，或下次 |
| $\text{V.ATK.lock}(x)$ | 永续攻击力增益 |
| $\text{V.ATK.once}(x)$ | 单次即刻攻击力增益 == 本回合下次 |


$i, j \in \{1, -1\}$，$1$=我方，$-1$=对方。

| 自然语言效果 | 事件表达式 | 说明 |
|:--|:--|:--|
| 选择我方一只怪物，本回合攻击力 +5 | $\text{V.ATK}(1,1,5)$ | $i=1,j=1,x=5$，发起者和目标同方 |
| 选择对方一只怪物，本回合防御力 -3 | $\text{V.DEF}(1,-1,-3)$ | $i=1,j=-1,x=-3$，我方发起减对方防 |
| 对方选择我方一只怪物，攻击力-4至我方回合结束 | $\text{V.ATK}(-1,1,-4)$ | 对方发起（$i=-1$），目标为我方（$j=1$） |
| 我方场上随机一只怪物下次攻击+7 | $\text{V.ATK.rand}(7)$ | 随机目标 |
| 此卡自身下次攻击 +6 | $\text{V.ATK.self}(6)$ | 无选择权，仅自身 |
| 【攻击技能】当次攻击 +6 | $\text{V.ATK.self.once}(6)$ | 单次即刻攻击力增益 |
| 【攻击技能】被攻击怪物当次防御-6 | $\text{-V.DEF.self.once}(-6)$ | 单次即刻防御力减损 |
| 我方场上一只怪物攻击力永久+5（可叠加） | $\text{V.ATK.lock}(5)$ | 锁定增益，持续生效 |
| 当我方怪物攻击对方防御力增加过的怪物时，该次攻击攻击力 +4 | $\text{Cond}(\text{V.DEF}(-1,-1, \ge 1)) + \text{V.ATK}(1,1,4)$ | 条件涉及对方给自己怪物加防 |
| 信仰-5，此卡本回合攻击力 +6 | $\text{DMG(-5)} + \text{V.ATK.self}(6)$ | 无选择权，仅自身 |
| 当我方受到($\ge 5$)伤害时，此卡本回合防御力 +6 | $\text{Cond}$($\text{DMG}$($\ge$ -5)) + $\text{V.ATK.self}(6)$ | 无选择权，仅自身 |


### 4. 手牌与盖牌
| 构造器 | 含义 |
|:--|:--|
| $\text{HC}(x)$ | 手牌数/盖牌数变化 $x$，$x>0$ 抽牌 |
| $\text{HC.M}(x)$ | 怪物卡手牌变化 |
| $\text{HC.P}(x)$ | 预言卡手牌变化 |

例如：
| 自然语言效果 | 事件表达式 | 说明 |
|:--|:--|:--|
| 我方抽 1 张牌 | $\text{HC}(1)$ | $x>0$ 抽牌 |
| 我方丢弃 1 张手牌 | $\text{HC}(-1)$ | 自选弃牌 |
| 破坏对方场上一张盖牌 | $\text{HC}(1，-1，-1)$ | |
| 我方盖 1 张牌 | $\text{HC}(-1) + \text{HC}(1)$ | |
| 对方随机丢弃 1 张手牌 | $-\text{HC.rand}(-1)$ | 对方弃牌，从我方视角取反 |
| 我方抽 2 张怪物卡 | $\text{HC.M}(2)$ | 限定怪物卡类型 |
| 当我方额外抽牌时，恢复 7 信仰 | $\text{Cond}(\text{HC}(1)) + \text{DMG}(7)$ | 条件事件 $\text{HC}(1)$ 代表“额外抽牌” |
| 当对方受到效果伤害时，我方抽 1 张牌 | $\text{Cond}(-\text{DMG.E}(\le -1)) + \text{HC}(1)$ | 条件事件用 $\text{Cond}$ 包装，下界估计取阈值 1 |
| 下次召唤高级怪物所需灵力 -2| $\text{Cond}_{Has}(\text{HC.M}(1, >1))*\text{MANA.rand}(1, 2)$ | 状态 $\text{HC.M}(1, >1)$ 代表“手牌有一只大于1级的怪物” |
| 抽牌抽到怪物卡为止 | $HC.M(1) + HC(x), x=$抽到怪物卡期望-1 | |


### 5. 场牌
| 构造器 | 含义 |
|:--|:--|
| $\text{FC}(i,j,x)$ | 场牌变化，含选择权 |
| $\text{FC.M}(i,j,x)$ | 怪物场牌变化，含选择权 |
| $\text{FC.P}(i,j,x)$ | 预言场牌变化，含选择权 |
|  $\text{FC.M}$， $\text{FC.P}$ | $\in \text{TargetAct}$ |

| 自然语言效果 | 事件表达式 | 说明 |
|:--|:--|:--|
| 从我方手牌召唤一只怪物到场 | $\text{FC.M}(1,1,1)$ | 我方发起，放置到我方场上 |
| 破坏对方场上一只怪物 | $\text{FC.M}(1,-1,-1)$ | 发起者我方，对方场上怪物 -1 |
| 将对方场上一只怪物返回手牌 | $\text{FC.M}(1,-1,-1) + (-\text{HC.M}(1))$ | 消灭场牌 + 对方抽一张怪物卡 |
| 将我方场上一只怪物返回手牌 | $\text{FC.M}(1,1,-1) + \text{HC.M}(1)$ | 自毁场面 + 我方抽怪物卡 |
| 对方破坏我方场上一只怪物 | $\text{FC.M}(-1,1,-1)$ | 对方发起，目标为我方场上 |
| 从牌堆召唤一只 0 级怪物 | $\text{FC.M}(1,1,1)$ | 事件本身同普通召唤，解码时用 $Q=1.25$ 体现检索优势 |
| 当我方额外召唤怪物时，对方受到 3 点效果伤害 | $\text{Cond}(\text{FC.M}(1,1,1)) + (-\text{DMG.E}(-3))$ | 条件 + 伤害，复用伤害构造器 |
| 将我方盖牌全部返回手牌后，抽3张牌 | $\text{FC.P.each}(-1) + \text{HC}(3)$  |  |
| 破坏对方一只拥有【通常属性】的怪物 |  $\text{Cond}_\text{has}(\text{FC.M.attr}(-1,\text{通常}))*\text{FC.M.rand}(-1)$  | 这里使用.rand是因为对方那只怪物有通常属性是相对随机的 |
| 破坏我方场上一张正面卡牌，我方场上一怪物下次攻击力+40（该攻击造成的战斗伤害除4） |  FC(1,1,−1)+AK(-1)+F(1,-1,-1) + DMG.A(10)  | 攻击力加的太多了，这里我们不用V.ATk了，就视为战斗破坏对方一只怪物, 伤害就近似估计为40/4=10 |
| 当我方覆盖怪物卡被攻击时：该攻击无效，且我方下回合所有怪物攻击力+该攻击怪物攻击力数值 | Cond(HC)   | 攻击力加的太多了，这里我们不用V.ATk了，就视为战斗破坏对方一只怪物, 伤害就近似估计为40/4=10 |

### 6. 行动
| 构造器 | 含义 |
|:--|:--|
| $\text{AK(i, j, x)}$ | $i$ 方选择 $j$ 方某怪物获得x次额外攻击 / 技能，含选择权 |
|  $\text{AK}$ | $\in \text{TargetAct}$ |

| 自然语言效果 | 事件表达式 | 说明 |
|:--|:--|:--|
| 选择我方一只怪物进行一次额外攻击 | $\text{AK}(1,1,1)$ | $x=1$ 表示一次行动 |
| 此卡攻击次数+1 | $\text{AK.self}(1)$ | 仅对该卡 |
| 对方一只怪物获得一次额外攻击 | $\text{AK}(-1,-1,1)$ | 对方发起给其自己怪物 |
| 当我方怪物发动攻击时，额外造成 4 点战斗伤害 | $\text{Cond}(\text{AK}(1,1,1)) + (-\text{DMG.A}(-4))$ | 行动触发追伤，复用伤害构造器 |
| 当我方怪物发动攻击时：此卡可以协同攻击。该怪物攻击力+此卡攻击力。（协同攻击消耗此卡攻击次数） | Cond(AK(1,1,1))+V.ATK(1,1,x)+AK.self(−1)$, x=攻击力期望 | |
